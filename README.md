# In the Middle of the Story

A story in three parts, starting from the "Protestant work ethic". Part I: how we got here (Weber, Franklin, Nietzsche, Rand). Part II: where you are (fracture, the search for signs). Part III: sane ways through (Tillich, Heschel, Frankl, Camus, Solzhenitsyn, Havel, Arendt). Appendix: criticisms, timeline, reading list with Amazon links. Set `amazon_tag` in `_config.yml` to add an Associates tag; books live in `_data/books.yml`.

Live site: https://techmore.github.io/protestant-work-ethic/

Built with Jekyll on GitHub Pages: shared layout in `_layouts/default.html`, nav order in `_data/nav.yml`, styles in `assets/style.css`. Edit any page's `.html` file and push; Pages rebuilds automatically.
